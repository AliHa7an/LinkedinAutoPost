Your sort just mutated the original array

sort() works in place. toSorted() makes a copy.

✗ sort()
const a = [3, 1, 2];
const b = a.sort((x, y) => x - y);

a === b; // true
a;       // [1, 2, 3] changed
✓ toSorted()
const a = [3, 1, 2];
const b = a.toSorted((x, y) => x - y);

a === b; // false
a;       // [3, 1, 2] intact

In UI code, copy first. Never sort shared state in place.
