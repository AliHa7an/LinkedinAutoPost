sort() compares numbers as strings

Without a compare function, "100000" comes before "21".

✗ Default
[1, 30, 4, 21, 100000].sort()
// [1, 100000, 21, 30, 4]
✓ Compare function
[1, 30, 4, 21, 100000]
  .sort((a, b) => a - b)
// [1, 4, 21, 30, 100000]

Not a plain string array? Always pass a compare function.
