An async forEach never waits for its promises

MDN's own example logs 0, not 14.

✗ forEach
ratings.forEach(async (r) => {
  sum = await add(sum, r);
});
console.log(sum); // 0
✓ for...of
for (const r of ratings) {
  sum = await add(sum, r);
}
console.log(sum); // 14

forEach discards return values. Use for...of or Promise.all.
