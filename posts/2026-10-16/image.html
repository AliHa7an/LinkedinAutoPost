fetch() won't throw on 500

Only network errors reject. HTTP errors resolve.

✗ Catch never runs
try {
  const res = await fetch(url);
  return await res.json();
} catch (e) { /* 500 skips this */ }
✓ Check ok, add timeout
const res = await fetch(url, {
  signal: AbortSignal.timeout(5000),
});
if (!res.ok) throw new Error(res.status);
return await res.json();

Resolved is not the same as successful.
