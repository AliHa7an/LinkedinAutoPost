Stop mutating arrays when you sort them

Use toSorted() to get a copy.

✗ sort()
const top = scores
  .sort((a, b) => b - a);

// scores changed too
✓ toSorted()
const top = scores
  .toSorted((a, b) => b - a);

// scores is untouched

On shared data, copy first. Then sort.
