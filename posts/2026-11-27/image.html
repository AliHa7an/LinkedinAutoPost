One failure shouldn't sink every result

Promise.all rejects on the first error. The rest keep running, unseen.

✗ Promise.all
await Promise.all([
  getUser(),    // ok
  getOrders(),  // fails
]);
// throws: user data lost
✓ Promise.allSettled
await Promise.allSettled([
  getUser(),
  getOrders(),
]);
// [{status:"fulfilled",value},
//  {status:"rejected",reason}]

Dependent tasks: all. Independent tasks: allSettled.
