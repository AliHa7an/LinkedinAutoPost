Deep copy or lossy copy?

The JSON round trip rewrites your data.

✗ JSON round trip
const s = new Set([1]);
JSON.stringify({ s, x: undefined });
// '{"s":{}}'
// cycles: TypeError
✓ structuredClone
const c = structuredClone(
  { s: new Set([1]) });
c.s.has(1); // true
// cycles: supported

Use JSON for JSON. Use structuredClone to copy state.
