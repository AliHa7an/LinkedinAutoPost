Node strips types. It can't generate enums

Use erasableSyntaxOnly to catch it early.

✗ Needs generated code
enum Role {
  Admin,
  User,
}
// Node: unsupported
// syntax
✓ Erasable
const Role = {
  Admin: "admin",
  User: "user",
} as const;
type Role = typeof Role[keyof typeof Role];

Also blocked: runtime namespaces and parameter properties.
