GitHub Actions

Give every job the least token access

Specify one permission, the rest become none.

✗ Unspecified
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - run: npm test
✓ Least privilege
jobs:
  test:
    permissions:
      contents: read
    steps:
      - run: npm test

Start at contents: read. Add more only when a step needs it.
