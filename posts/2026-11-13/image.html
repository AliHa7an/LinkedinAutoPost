JSON.parse can change your ID silently

Numbers above 253−1 get rounded, no error.

✗ Number
JSON.parse(
  '{"id":9007199254740993}'
).id
// 9007199254740992
✓ String
const o = JSON.parse(
  '{"id":"9007199254740993"}');
BigInt(o.id)
// 9007199254740993n

Send 64-bit IDs as strings. Convert to BigInt only for math.
