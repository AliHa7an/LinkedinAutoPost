Group an array in one line, not five

Object.groupBy returns a null-prototype object.

✗ reduce
orders.reduce((acc, o) => {
  (acc[o.status] ||= []).push(o);
  return acc;
}, {});
✓ groupBy
Object.groupBy(
  orders, o => o.status
);
// non-string keys: Map.groupBy

Groups hold the same objects, not copies.
