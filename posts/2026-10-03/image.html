$ git push --force

after a rebase, pick the safer flags
✗ BLIND
$ git push --force
Overwrites the remote branch. Teammate's new commit? Gone.
~ LEASE
$ git push --force-with-lease
Fails if the remote moved. Background fetch can fool it.
✓ SAFEST
$ git push --force-with-lease --force-if-includes
Also checks you integrated the remote tip.
