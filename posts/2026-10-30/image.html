A caught error is not always an Error

throw accepts any value, so catch gets unknown.

✗ catch as any
catch (err) {
  log(err.message);
}
// throw "oops" → undefined
✓ catch as unknown
catch (err) {
  if (err instanceof Error)
    log(err.message);
}

Narrow once at the boundary. Throw real Error objects.
