Catch the typo, keep the narrow type

TypeScript 4.9 added satisfies.

✗ Annotation
const palette: Record<Colors,
  string | RGB> = { ... };

palette.green.toUpperCase();
// error: not on string | RGB
✓ satisfies
const palette = {
  ...
} satisfies Record<Colors,
  string | RGB>;

palette.green.toUpperCase(); // ok

Check the shape. Keep the precise type.
