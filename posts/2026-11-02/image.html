Why map(parseInt) returns NaN

map passes the index. parseInt reads it as the radix.

✗ Index becomes radix
["1","2","3"].map(parseInt);
// [1, NaN, NaN]
✓ Wrap it
["1","2","3"].map(
  (s) => parseInt(s, 10));
// [1, 2, 3]

Don't pass functions with optional parameters straight into map.
