One failure shouldn't hide nine successes

Promise.all is fail-fast. allSettled keeps every outcome.

✗ Promise.all
const r = await Promise.all(jobs);
// 1 rejects → throws
// other 9 results: lost
✓ Promise.allSettled
const r = await Promise.allSettled(jobs);
// [{ status: "fulfilled", value },
//  { status: "rejected", reason }]

Need every outcome? allSettled. Parts useless alone? all.
