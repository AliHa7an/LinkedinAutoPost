Casting API data is not validating it

as is erased at compile time.

✗ Trusts the API
const user = (await res.json())
  as User;

// wrong shape? no error here
✓ Checks at runtime
const r = User.safeParse(
  await res.json());
if (!r.success) throw r.error;
// r.data is a real User

Use as for what you know. Parse what you receive.
