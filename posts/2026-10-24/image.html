Your default just overrode a valid 0

|| replaces any falsy value. ?? only null and undefined.

✗ Using ||
const count = 0;

count || 42;
// 42  (0 is lost)
✓ Using ??
const count = 0;

count ?? 42;
// 0  (kept)

Use ?? for defaults. Reserve || for "any falsy".
