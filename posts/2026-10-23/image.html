Don't escape input. Parameterize it

Sort columns and table names need an allow-list.

✗ Input becomes code
db.query(
  `SELECT * FROM users
   WHERE email = '${email}'`
);
✓ Input stays data
db.query(
  "SELECT * FROM users
   WHERE email = $1",
  [email]
);

Values go in parameters. Identifiers come from a fixed list.
