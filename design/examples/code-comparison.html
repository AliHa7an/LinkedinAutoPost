Stop a default value from widening your generic

TypeScript 5.4 added NoInfer<T> for exactly this.

✗ Without
function pick<C extends string>(
  colors: C[], fallback?: C) {}

pick(["red","green"], "blue"); // no error
✓ With NoInfer
function pick<C extends string>(
  colors: C[], fallback?: NoInfer<C>) {}

pick(["red","green"], "blue"); // error ✓

Let one parameter decide the type. Block the others from changing it.
